# mhfu-studio

One window for authoring MHFU mods offline: a ported monster (its clips, parts, hitboxes and
moves) and map edits (mesh, collision, textures), with the commands behind both.

```bash
uv run studio            # the window
uv run studio --help     # the commands: render, port, map
```
